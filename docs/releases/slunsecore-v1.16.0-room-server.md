## SlunseCore changes

- SlunseCore integration branch merged with upstream v1.16.0; no additional room-server-specific UI changes in this release.

See the [official MeshCore v1.16.0 release notes](https://blog.meshcore.io/2026/06/06/release-1-16-0) for new features, bug fixes, and supported devices.
